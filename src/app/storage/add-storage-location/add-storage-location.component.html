About Storage Locations

Storage locations are physical places where key cabinets are installed. You can add multiple cabinets and hooks/slots inside each location.

Examples:

  • Head Office Safe Room
  • Security Control Room
  • Manchester Branch Store
  • Mobile Key Van

What's Next?

After creating a storage location, you can:

  • 1 Add cabinets to this location
  • 2 Generate hooks/slots in cabinets
  • 3 Assign keys to hooks/slots

Important Notes

  • All fields marked with * are required.
  • Location code is auto-generated and must be unique.
  • You can add cabinets after saving this location.
  • Deactivated locations cannot be deleted if they contain cabinets, hooks or keys.
