About Storage Locations

Storage locations are physical places where key cabinets are installed. You can add multiple cabinets and hooks/slots inside each location.

Examples:

  • •Head Office Safe Room
  • •Security Control Room
  • •Manchester Branch Store
  • •Mobile Key Van

What Happens Next?

After reactivation:

  1. 1This location will be marked as active.
  2. 2You can assign keys to hooks/slots.
  3. 3You can add cabinets to this location.
  4. 4Location will be available for storage operations.

Important Notes

  • •Reactivate the location only when it is safe and ready to use.
