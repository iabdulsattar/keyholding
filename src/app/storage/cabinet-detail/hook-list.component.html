Deactivate Cabinet?

You are about to deactivate "Cabinet A - Main Floor" (CAB-0001).

This cabinet has 14 keys on 14 hooks.

All keys and hooks in this cabinet must be removed before it can be deactivated.

What happens when deactivated:

  • The cabinet will be marked as inactive.
  • It will no longer be available for key storage.
  • It will not appear in active cabinet lists or hook assignments.
  • You can reactivate this cabinet at any time.

Reactivate Cabinet?

You are about to reactivate "Cabinet A - Main Floor" (CAB-0001).

This cabinet is currently inactive.

All keys and hooks will be available for use once the cabinet is reactivated.

What happens when reactivated:

  • The cabinet will be marked as active.
  • It will be available for key storage and assignments.
  • It will appear in active cabinet lists and hook assignments.
  • You can deactivate this cabinet at any time.
