About Storage Locations

Storage locations are physical places where key cabinets are installed. You can add multiple cabinets and hooks/slots inside each location.

Examples:

  • Head Office Safe Room
  • Security Control Room
  • Manchester Branch Store
  • Mobile Key Van

What Happens Next?

After deactivation:

  • 1 This location will be marked as inactive.
  • 2 New keys cannot be assigned or moved to this location.
  • 3 Existing keys remain in place but cannot be managed here.

Important Notes

  • Deactivated locations cannot be deleted if they still contain keys, cabinets or hooks.
  • Reactivate the location to continue using it for key storage operations.
