About Cabinets

Cabinets are used to organize and securely store keys within a storage location. Each cabinet contains multiple hooks/slots for key storage.

Examples:

  • •Standard Key Cabinet
  • •Fire Rated Cabinet
  • •High Security Cabinet
  • •Modular Cabinet

What's Next?

  3. 3 Manage access logs and audit trail

Important Notes

  • •Cabinet code is auto-generated and must be unique within the location.
  • •You can generate hooks/slots after creating the cabinet.
  • •Ensure the cabinet is properly secured and access is restricted.
